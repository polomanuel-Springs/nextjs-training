# What I understood

- I learned that nested folders create nested routes.
- A folder named [id] lets one page handle different product identifiers.
- In Next.js 16, I await params before reading values in an async server page.
- I use Link for navigation and notFound when a requested record does not exist.
- A catch-all route captures several segments; an optional catch-all also permits no segments.
- Layouts can preserve shared interface state, while templates remount during navigation.
