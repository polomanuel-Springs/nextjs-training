# What I understood

- I learned that server validation is required even when a form also validates in the browser.
- Zod safeParse returns either validated data or structured validation errors.
- useActionState connects an action result to the client interface.
- useFormStatus exposes the pending state from a component inside the form.
- Field errors should appear beside the related inputs and be linked through accessible attributes.
- Successful validation does not mean a message was sent or a record was saved.
