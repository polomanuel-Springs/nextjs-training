# What I understood

- I learned that metadata describes a page for browsers, search engines, and sharing previews.
- A Server Component can export metadata for fixed values or generateMetadata for data-dependent values.
- A parent title template can combine the page title with the site name.
- Canonical URLs identify the preferred public address for content.
- Sitemap and robots files describe public discovery and crawling behavior.
- Open Graph image URLs and canonical domains need real deployment values before publishing.
